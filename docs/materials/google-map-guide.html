1. あなたの院は大丈夫？ セルフチェック

当てはまらない項目が多いほど、新しい患者さんに見つけてもらいにくい状態です。

  • 直近1ヶ月以内に、Googleマップへ写真や近況を投稿した
  • クチコミへの返信を1ヶ月以内に行っている
  • 営業時間・休診日（お盆や年末年始も含む）が最新の状態になっている
  • ホームページのURLがGoogleビジネスプロフィールに正しく登録されている
  • マップから電話・予約フォームなど、連絡できる導線がすぐ分かる
  • カテゴリ設定が「接骨院」など、実態と合った内容になっている
  • 院内・外観・スタッフの写真が10枚以上登録されている
  • 「商品」「サービス」欄に、対応できる施術メニューを入力している

当てはまった数が3個以下の場合は、「登録しただけで放置されている」状態の可能性が高いです。

2. なぜ「登録しただけ」では見つからないのか

指名検索と、一般検索の違い

院名で検索されて表示される「指名検索」と、「地域名＋整骨院」のような一般検索で表示されることは別物です。登録して放置している状態だと、すでに院名を知っている人にしか表示されず、新しい患者さんの検索には出てきません。

「放置」はGoogle側にも伝わる

海外のGoogleビジネスプロフィール運用ガイドでは、30日以上投稿や写真の更新がないプロフィールは表示回数が大きく落ち込む傾向が報告されています。反対に、週1〜2回程度の更新を継続しているプロフィールは表示機会が維持されやすいとされています。「頑張って毎日更新する」よりも「止めない」ことの方が重要です。

✕ 見つかりにくい状態

登録したまま更新が止まっている／クチコミへの返信がない／営業時間が古いまま／写真が数枚しかない

◯ 見つかりやすい状態

週1回程度の投稿がある／クチコミに返信している／情報が常に最新／写真が充実している

3. カテゴリ設定の考え方

Googleビジネスプロフィールには「メインカテゴリ」を1つと、「サブカテゴリ」を最大9つまで追加できます。カテゴリはマップでの表示・検索結果に大きく影響する設定のひとつです。実態と異なる広すぎるカテゴリより、実際の施術内容に合った具体的なカテゴリを選ぶことが基本です。

設定例備考
メインカテゴリ：接骨院／整骨院柔道整復師が施術する事業所として実態に合ったカテゴリを選ぶ
サブカテゴリ：マッサージ療法士／スポーツマッサージセラピスト　等対応できる施術内容に応じて、実態と合うものだけを追加

「商品」「サービス」欄も活用する

カテゴリに加えて、プロフィール内の「商品」「サービス」欄に対応メニュー（交通事故施術、腰痛・肩こりの施術など）を登録すると、検索での見つかりやすさに繋がります。各メニューには個別の写真を添えるとより分かりやすくなります。

※症状名・効果を強調する表現（「腰痛が治る」等）は広告ガイドライン上避けるべき表現です。「〇〇の施術に対応」という書き方にとどめてください。

4. 写真・動画を充実させる

海外の調査では、写真を100枚以上登録しているプロフィールは、数枚しか登録していないプロフィールに比べてプロフィール閲覧数・経路検索数が大きく伸びる傾向が報告されています。枚数を一度に揃える必要はありませんが、少しずつ充実させていく価値はあります。以下のような写真を意識的に集めてみてください。

外観・入口
受付・待合室
施術ベッド・院内
スタッフの様子
資格証・掲示物
駐車場・アクセス

動画も効果的

「院内紹介」「院長からのごあいさつ」といった短い動画も、来院前の患者さんの不安を減らすのに役立つとされています。スマホで撮影した数十秒の映像でも十分です。

5. 投稿の実例テンプレート

投稿は「頻度」より「継続」が大切です。いきなり毎日投稿する必要はありません。週1回でも継続していることが評価されます。以下はそのまま使える文例です。

営業日・休診日のお知らせ 【休診日のお知らせ】 〇月〇日（〇）は誠に勝手ながら休診とさせていただきます。 ご不便をおかけしますが、何卒よろしくお願いいたします。
季節のごあいさつ・近況 暑い日が続いていますね。当院では冷房を効かせて快適な状態で施術を受けていただけるようにしています。 体調管理が難しい時期ですので、お身体のことでお困りの際はお気軽にご相談ください。
対応メニューの紹介 交通事故後のお身体のケアにも対応しております。 「保険が使えるのか分からない」という方もまずはお気軽にお問い合わせください。
写真だけの近況投稿 （院内の様子や季節の飾り付けなど、一言コメントを添えて写真を投稿するだけでもOKです）

6. クチコミの増やし方・返信のコツ

お願いの仕方

会計時に「良ければ、Googleに一言だけでも感想をいただけると嬉しいです」と直接お願いするのが最も効果的とされています。QRコード付きのカードを受付や施術ベッド脇に置いておくと、お願いしやすくなります。

クチコミには、良い評価・悪い評価にかかわらず、できるだけ返信することが信頼につながります。以下は返信の文例です（効果を保証する表現は使っていません）。

高評価への返信例 ご来院・クチコミの投稿をありがとうございます。スタッフ一同、大変励みになります。今後ともお身体のことでお困りの際はいつでもご相談ください。
改善要望への返信例 貴重なご意見をいただき、ありがとうございます。ご不便をおかけしましたこと、お詫び申し上げます。いただいたご意見は院内で共有し、改善に努めてまいります。

NG「〇〇が治りましたね」等、効果を断定・保証する返信   OK 感謝と今後の対応を伝える返信

7. 予約・連絡導線を分かりやすくする

リンク設定は「ホームページ」を基本に

プロフィールのボタンを「電話」だけにしてしまうと、診療中で電話に出られない時間帯の機会を逃してしまいます。ホームページやWeb予約ページへのリンクを設定し、電話に出られない時間でも情報を確認・予約できる状態にしておくと取りこぼしが減ります。
