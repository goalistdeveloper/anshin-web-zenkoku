## ① 実績セクション（数字で見る、安診Webの実績）

**配置場所**: 「03 作って終わりじゃない、成果を出すのも私たちの仕事です」セクションと「導入事例」セクションの間

**見出し**
```
数字で見る、安診Webの実績
```

**リード文**
```
2026年◯月時点、安診Webをご利用中の全17院の実績です（院名は伏せています）
```
※◯月は実際の集計月に差し替えてください。

**KPIタイル（4つ横並び）**

| 数字 | ラベル |
|---|---|
| 17院 | 導入院数 |
| 153件 | Googleマップ経由 累計予約数 |
| 4.7★ | クチコミ平均評価 |
| 16.5件 | クチコミ平均件数／院 |

**注釈（タイル下に小さく）**
```
※運用期間（1〜8ヶ月）・院の規模により結果は異なります。特定の院を選んで掲載したものではなく、導入中の全17院を対象に集計しています。
```

**デザイン指定**: 数字は赤(#FF0000)・太字。カード枠は薄いピンク(#FFECEC)の2px枠線、白背景、角丸14px程度。既存の赤バッジ・問題提起ボックスと同系統のトーン。

**根拠データ（内部用・非表示）**: ご提供いただいたスプレッドシート（17院、Googleマップ経由予約数）から算出。
- 累計予約数合計: 153件（全17院の合計）
- クチコミ評価平均: 4.7★（80.0点 ÷ 17院）
- クチコミ件数平均: 16.5件（280件 ÷ 17院）
- 特定の1院を抜き出さず全院平均で提示 → 優良誤認表示（実績の誇張・良い例の抜粋）を回避

## ② 導入事例カードに実際のHP画像を追加

**配置場所**: 既存の「導入事例」セクション、各証言カード内（現状：顔写真＋文章のみ→ 右側に実際のHP画像を追加）

**カード1: 和漢整骨院（高橋様）**
- 既存の顔写真: そのまま使用（本番サイト掲載の実写真）
- 追加するHP画像ファイル: `assets/img/seikotsuin-fv-wakan-sekkotsuin.jpg`
- 画像キャプション: `実際に制作したホームページ`
- 既存テキスト・リンクは変更なし

**カード2: ホーセイ堂接骨院（市川先生）**
- 既存の顔写真: そのまま使用（本番サイト掲載の実写真）
- 追加するHP画像ファイル: `assets/img/seikotsuin-fv-kotsuban-housei.jpg`
- 画像キャプション: `実際に制作したホームページ`
- 既存テキスト・リンクは変更なし

**レイアウト指定**: 顔写真（左）／証言文（中央）／HP画像＋キャプション（右）の3カラム。モバイルでは縦積み。HP画像は角丸10px・薄い枠線(#E5E5E5)。

**注意**: 新規に作成・加工した画像は使用していません。顔写真は本番サイトに既に掲載されている実写真、HP画像はこのプロジェクトの`assets/img`にある実際のスクリーンショットです。

## ③ PC版 LINE動線

**配置1: ヘッダー右側**（電話番号の右、「無料で相談する」ボタンの左）

ボタン文言:
```
LINEで相談
```
- 背景色: LINE公式グリーン `#06C755`
- アイコン: LINE公式の吹き出しロゴ（白）
- 形状: 角丸ピル、既存の青グラデーションCTAと横並び

**配置2: お問い合わせ直前の独立セクション**

見出し:
```
まずはLINEで、気軽にご相談ください
```

本文:
```
お電話やフォームの前に、「こんなことも聞いていいのかな」をLINEで気軽に聞いてみませんか。担当者が直接お答えします。
```

ボタン文言:
```
LINE公式アカウントを友だち追加
```

**必要な準備**: LINE公式アカウントのID／友だち追加URLをご用意ください。いただき次第、各ボタンのリンク先に設定します。
