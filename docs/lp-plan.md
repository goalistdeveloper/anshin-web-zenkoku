## 1. ペルソナ（要約）

藤原智仁先生・40代・一人院長。10年前に作ったHPがギリギリスマホ対応、休診日も載せられず、予約フォームなし、GA未活用、院のSNSなし。来院が減っていて「何かやりたい」とは思っている。ネットリテラシーは中の下（スマホゲーム・カーナビ的なGoogleマップ利用はする）。

**LP設計への含意**
- 検索広告をクリックして来る＝「整骨院 ホームページ」等で能動的に調べた瞬間の人。共感より先に「何が・いくらで・どうなるか」を速く見せる。
- Zoom・オンライン完結は本人にとって不安要素。FAQ送りにせず本文で先回りして潰す。
- 専門用語（SEO/MEO/CVR/CMS）は使わない。現行LPのトーンを継承。
- 診療中は電話に出られない → 連絡手段の選択肢と時間帯配慮を見せる。

## 2. 戦略方針

1. **広告受けLPとして設計する**
   - 見出しは検索語（ホームページ制作/リニューアル×整骨院）と一致させる。
   - 価格をファーストビュー直下に出す。広告経由の訪問者は比較検討中であり、価格を隠すと離脱する。
   - グローバルナビは最小限（ページ内アンカーのみ）。外部リンクで逃がさない。
   - CTAは追従（スマホ下部固定バー）+ セクション間に計4〜5回。

2. **実績数字ゼロを「明朗さ」と「顔」で補う**
   - 数字の代わりに信頼を作る要素: ①料金の完全明朗表示（追加費用なし・解約条件も隠さない）②担当者の顔写真と名前 ③6ヶ月契約の理由を正直に説明 ④運用レポートの実物サンプル画像 ⑤制作見本（デモサイト or ビフォーアフターのモック）。
   - 既存事例（和漢整骨院・ホーセイ堂）は「声」として利用可。ただし訪問前提時代の文脈が滲む表現は削る。

3. **「対面訪問」ブランドの語り直し**
   - 現行LPの「私たちが会いに行きます」は使わない。価値の核を「距離」から「頻度と継続」へ：*会いに行く代わりに、毎月画面越しに作戦会議をする*。
   - 現行比較表の「Zoom＝一般制作会社の連絡手段」という対比は全国版では自己否定になるため全面改訂。比較軸は「作った後、誰が運用するか」に変更。

4. **写真撮影ガイドブックを弱点から武器に変える**
   - 「訪問しないから撮影できない」ではなく「先生がいつでも撮り直せる体制を作る」と語る。
   - ガイドブックはリードマグネットとしても機能させる（無料相談までいかない層向けの第2CTA「資料＋ガイドブックをもらう」）。広告費の回収率が上がる。

## 3. セクション構成とコピー案

### S1. ファーストビュー
- バッジ: `整骨院・接骨院専門` `全国対応` `打ち合わせはオンライン`
- H1（案A）: **新規患者をとりこぼさないホームページを、全国どこでも。**
- H1（案B・広告一致重視): **整骨院専門のホームページ制作、オンラインで丸ごとおまかせ。**
- サブ: 初期費用99,000円（税込）・月額9,000円（税込）。制作も、毎月の更新も、Googleマップ対策も。打ち合わせはZoomで30分から。
- CTA主: 「無料相談する（Zoom・電話・LINEが選べます）」
- CTA副: 「サービス資料をもらう」
- ビジュアル: 緑基調。院長がタブレット/PC越しに担当者と話している構図＋完成HPのスマホモック。

### S2. 問題提起「あなたのホームページは大丈夫ですか？」
現行の5項目を継承しつつペルソナ直撃に調整:
1. 休診日やお盆・年末年始の案内が載せられない
2. スマホで見ると字が小さい・崩れる（10年前の設計のまま）
3. 予約は電話のみ。診療中・休診日の予約をとりこぼしている
4. 情報が古いまま放置されて、患者さんの信頼を失っている
5. 誰が何人見に来ているのか、まったく分からない

締め: 「直したい気持ちはあるのに、日々の施術で手が回らない。——それが一番もったいない状態です。」

### S3. 【新設】オンラインで、ここまでできます
Zoom不安の先回りセクション。3つの小見出し:
- **打ち合わせは、届いたURLをタップするだけ。** アプリの準備も設定も不要。初回は電話で接続までご案内します。1回30分、診療前・昼休み・診療後から選べます。
- **写真は、先生のスマホで十分きれいに撮れます。** プロ監修の「写真撮影ガイドブック」をお渡しします。構図・明るさ・撮る場所のチェックリスト付き。撮った写真はLINEで送るだけ。（→ ガイドブック表紙＋中面のサンプル画像を掲載）
- **契約から公開まで、一度もご来社・ご訪問は不要です。** 電子契約・オンライン入稿で完結。全国どこの院でも同じ品質・同じ料金です。

### S4. ソリューション3本柱（現行を継承・調整）
- 01 患者さんに見つけてもらえるホームページ（「地域名＋整骨院」で検索した患者さんに届く設計）
- 02 Googleマップで選ばれる評判づくり
  - 自分ごと化コピー: 「先生も、初めての場所を探すときはGoogleマップを使いませんか？ 患者さんも同じです。」
  - クチコミ促進カード・卓上POPは**データ支給＋印刷手配**方式に変更（訪問設置が不要な形に文言調整）
- 03 作りっぱなしにしない、毎月の作戦会議
  - 運用レポートの実物サンプル画像を掲載（数字はダミーで可、見た目の分かりやすさを見せる）
  - 「毎月◯分のオンライン作戦会議」と頻度を明示できると強い（要サービス設計確認）

### S5. 制作見本 / ビフォーアフター
